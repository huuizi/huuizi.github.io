# Huizi’s Forest

A bilingual personal website, built with static HTML, CSS, JavaScript, and paper-cut artwork.

## Local preview

Run `python3 -m http.server 4173` from this directory and open http://localhost:4173. No build step is required.

## GitHub Pages

Publish from the `main` branch and the `/ (root)` folder in the repository’s Pages settings. All website paths are relative, so the same files work on an account site or a project site. The `.nojekyll` file keeps deployment buildless.
